# WoW Compagnon

User-owned unified module, independent of AzerothCore. Maintain only this repository.
Do not synchronize native Playerbots/PBC repositories. Keep the imported licenses,
author notices and Git histories. Build against both official AzerothCore and the
personal fork, without required core patches. Keep legacy configuration names and
data formats compatible. Never publish runtime credentials, cards, choices or memories.
Production source: src/gameplay, src/narrative. Standalone tests: tests.
Read the enclosing core guidelines for builds, C++ and review. Do not run live e2e.
